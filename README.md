# WooCommerce Product Data for AI

This Python script demonstrates how to structure WooCommerce product data into a format easily consumable by AI assistants like ChatGPT, Claude, and Gemini. It extracts key fields such as name, description, price, category, and URL for better discoverability.

## Language

`python`

## How to Run

Save the code as `generate_product_data.py` and run it from your terminal using `python generate_product_data.py`.
